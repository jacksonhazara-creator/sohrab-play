# Sohrab — playable web build

Play in the browser: https://jacksonhazara-creator.github.io/sohrab-play/

This repository only holds the exported web version of the game (Godot 4.7.2, single-threaded
web export, so it runs on GitHub Pages). The source code is in a separate private repository.
Controls: A/D or arrows to move, W/Space to jump, C to crouch, F/J sickle, E/K interact, Esc pause.
